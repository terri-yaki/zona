# Your PCs, one pocket inbox

Bring alerts from different computers together and always know where each one came from.

## Every PC has a name

Each alert shows its source, so work, home, and server messages never blur together.

## Seven days at a glance

Search recent alerts by computer, time, or unread status whenever a push arrives at the wrong moment.

## One key per computer

Disconnect one machine without interrupting the rest of your setup.
